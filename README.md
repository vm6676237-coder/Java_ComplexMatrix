# Java_ComplexMatrix
# Калькулятор матриц над комплексными числами

Консольное приложение для работы с матрицами, элементами которых являются комплексные числа вида `a + bi`.

## О программе

Программа предоставляет консольный интерфейс для работы с матрицами, элементами которых являются комплексные числа вида `a + bi`. Матрицы хранятся в памяти (до 1000 штук), каждой автоматически присваивается имя: `A`, `B`, `C`, …, `Z`, `AA`, `AB`, … (как столбцы в Excel).

Каждое комплексное число вводится парой: сначала действительная часть, потом мнимая. Разделитель — пробел, запятая или точка с запятой.

## Запуск

```bash
javac Main.java Matrix.java Complex.java
java Main
```

После запуска вы увидите главное меню.

## Главное меню

```
=== Калькулятор матриц над комплексными числами ===

Доступные матрицы: (пусто)

Выберите действие:
  1) Создать матрицу
  2) Сложить две матрицы
  3) Вычесть две матрицы
  4) Умножить две матрицы
  5) Умножить матрицу на комплексное число
  6) Транспонировать матрицу
  7) Найти детерминант
  8) Найти обратную матрицу
  9) Разделить матрицу на матрицу
 10) Показать матрицу
 11) Удалить матрицу
  0) Выход
Ваш выбор:
```

- Строка **«Доступные матрицы»** всегда показывает, какие матрицы сейчас существуют. В начале — `(пусто)`.
- Введите число от `0` до `11` и нажмите Enter.
- `0` — выход из программы.

### Если ввести что-то не то

- **Пустая строка** или строка из пробелов — программа просто ждёт ввод снова.
- **Не число** (например, `abc`):

  ```
  Ожидалось целое число, повторите:
  ```

- **Число вне 0–11** (например, `42`):

  ```
  Нет такого пункта.
  ```

  и возврат в меню.

## Общие правила ввода

Везде, где программа просит комплексное число (`re im`):

- Пишите **два числа через пробел**: `3 4` → это `3 + 4i`.
- Можно через запятую: `3,4`.
- Можно через точку с запятой: `3;4`.
- Десятичный разделитель — точка: `1.5 2.5` → `1.5 + 2.5i`.
- Отрицательные числа: `-3 -4` → `-3 − 4i`.
- Экспонента работает: `1e-3 2e2` → `0.001 + 200i`.

### Что НЕ принимается

- Одно число вместо двух: `3` →

  ```
  Ожидались два числа (re im), повторите:
  ```

- Три числа: `3 4 5` → та же ошибка.
- Буквы: `a b` →

  ```
  Не удалось разобрать числа, повторите:
  ```

- Пустая строка — программа ждёт заново, ничего не печатает.

## Функции

### 1. Создать матрицу

**Что делает:** создаёт новую матрицу заданного размера, заполняет её введёнными комплексными числами, сохраняет в первый свободный слот.

**Правильный сценарий:**

```
Ваш выбор: 1
Матрица будет сохранена как A.
Сколько строк? 2
Сколько столбцов? 2
Введите элементы построчно в формате: re im (можно через пробел или запятую).
  [0][0]: 1 2
  [0][1]: 3 4
  [1][0]: 4 3
  [1][1]: 2 1
Матрица A создана:
1.0+2.0i 3.0+4.0i 
4.0+3.0i 2.0+1.0i 
```

**Ошибки:**

- Размер ≤ 0:

  ```
  Сколько строк? 0
  Сколько столбцов? 5
  Размеры должны быть положительными.
  ```

- Хранилище заполнено (1000 матриц):

  ```
  Хранилище заполнено (1000 матриц). Удалите что-нибудь.
  ```

---

### 2. Сложить две матрицы

**Что делает:** покомпонентно складывает две матрицы одинакового размера. Результат сохраняется в первый свободный слот.

**Правильный сценарий:**

```
Ваш выбор: 2
Укажите первую матрицу (например, A, B, ...; 0 — отмена): A
Укажите вторую матрицу (например, A, B, ...; 0 — отмена): B
Результат сохранён как C  [A + B]:
...
```

**Ошибки:**

- Отмена: ввод `0` →

  ```
  Укажите первую матрицу (...): 0
  ```

  просто возвращает в меню, ничего не выводится.

- Несуществующее имя (например, `Z`, когда `Z` не создана) →

  ```
  Матрица Z не создана.
  ```

- Имя вне диапазона (например, `AAAA`) →

  ```
  Нет такой матрицы.
  ```

- Разные размеры:

  ```
  Ошибка: Размеры матриц не совпадают
  ```

---

### 3. Вычесть две матрицы

Работает так же, как сложение, только `A - B`. Все ошибки — те же.

**Правильный вывод:**

```
Результат сохранён как C  [A - B]:
...
```

---

### 4. Умножить две матрицы

**Что делает:** матричное умножение `A · B`. Требует, чтобы число столбцов `A` равнялось числу строк `B`.

**Правильный сценарий:**

```
Ваш выбор: 4
Укажите первую матрицу (...): A
Укажите вторую матрицу (...): B
Результат сохранён как C  [A * B]:
...
```

**Ошибки:**

- Несовместимые размеры (например, `2×3` умножить на `2×2`):

  ```
  Ошибка: Длина строка первой матрицы не равна длине столбца второй матрицы
  ```

- Всё остальное — как в сложении.

---

### 5. Умножить матрицу на комплексное число

**Что делает:** умножает каждый элемент матрицы на заданное комплексное число.

**Правильный сценарий:**

```
Ваш выбор: 5
Укажите исходную матрицу (...): A
Скаляр re im: 2 0
Результат сохранён как B  [A * (2.0+0.0i)]:
4.0+4.0i 6.0+8.0i 
8.0+6.0i 4.0+2.0i 
```

**Ошибки:**

- Скаляр введён неправильно (не два числа) — та же защита, что и у `readComplexLine`:

  ```
  Скаляр re im: abc
  Ожидались два числа (re im), повторите: 
  ```

---

### 6. Транспонировать матрицу

**Что делает:** `Aᵀ` — меняет строки и столбцы местами. Размер становится `col × row`.

**Правильный сценарий:**

```
Ваш выбор: 6
Укажите исходную матрицу (...): A
Результат сохранён как B  [T(A)]:
1.0+2.0i 4.0+3.0i 
3.0+4.0i 2.0+1.0i 
```

**Ошибки:**

- Нет исходной матрицы →

  ```
  Матрица A не создана.
  ```

- Отмена (`0`) — выход в меню.

---

### 7. Найти детерминант

**Что делает:** вычисляет детерминант квадратной матрицы методом Гаусса с выбором ведущего элемента.

**Правильный сценарий:**

```
Ваш выбор: 7
Укажите исходную матрицу (...): A
det(A) = 0.000000-20.000000i
```

**Ошибки:**

- Не квадратная (например, `2×3`):

  ```
  Ошибка: Невозможно определить детерминант. Матрица не является квадратной
  ```

**Замечание про точность.** Из-за чисел с плавающей точкой вы можете увидеть что-то вроде:

```
det(A) = 3.469446951953614E-18-20.000000i
```

Это не ошибка, а машинный ноль. Реальная часть — это `0` с точностью до `1e-16`.

---

### 8. Найти обратную матрицу

**Что делает:** методом Гаусса–Жордана находит `A⁻¹`. Требует, чтобы матрица была квадратной и невырожденной.

**Правильный сценарий:**

```
Ваш выбор: 8
Укажите исходную матрицу (...): A
Результат сохранён как B  [inv(A)]:
...
```

**Ошибки:**

- Не квадратная →

  ```
  Ошибка: Обратная матрица существует только для квадратной
  ```

- Вырожденная (детерминант = 0) →

  ```
  Ошибка: Матрица вырождена, обратной не существует
  ```

---

### 9. Разделить матрицу на матрицу

**Что делает:** `A / B = A · B⁻¹`. Требует, чтобы `B` была квадратной и невырожденной, а число столбцов `A` совпадало с числом строк `B`.

**Правильный сценарий:**

```
Ваш выбор: 9
Укажите первую матрицу (...): A
Укажите вторую матрицу (...): B
Результат сохранён как C  [A / B]:
...
```

**Ошибки:**

- Размеры не сходятся:

  ```
  Ошибка: Деление выполнить не удается. Длины строки первой и столбца второй матриц не равны
  ```

- `B` не квадратная:

  ```
  Ошибка: Вторая матрица не является квадратной
  ```

- `B` вырождена — пробросится ошибка из `inverse`:

  ```
  Ошибка: Матрица вырождена, обратной не существует
  ```

---

### 10. Показать матрицу

**Что делает:** выводит сохранённую матрицу на экран.

**Правильный сценарий:**

```
Ваш выбор: 10
Укажите нужную матрицу (...): A
Матрица A:
1.0+2.0i 3.0+4.0i 
4.0+3.0i 2.0+1.0i 
```

**Ошибки:**

- Если такой матрицы нет:

  ```
  Матрица A не создана.
  ```

---

### 11. Удалить матрицу

**Что делает:** освобождает слот. При следующем создании новая матрица займёт это имя.

**Правильный сценарий:**

```
Ваш выбор: 11
Укажите ненужную матрицу (...): B
Матрица B удалена.
```

**Ошибки:**

- Нет такой матрицы →

  ```
  Матрица B не создана.
  ```

**Замечание.** Удаление не сдвигает остальные матрицы. Если удалить `B`, то `A` и `C` останутся на своих местах. Новая матрица займёт именно слот `B`.

---

## Имена матриц

- Первая свободная ячейка → `A`, затем `B`, `C`, …, `Z`, `AA`, `AB`, … до `ALL` (индекс 999).
- Регистр не важен: `a`, `A`, `aa` — одно и то же.
- Ввод имени вне диапазона (например, `ZZZ`) → `Нет такой матрицы.`

**Пример цепочки:**

```
1) Создать → A
2) Создать → B
3) Умножить A на B → C  [A * B]
4) Транспонировать C → D  [T(C)]
5) det(D) → вывод
6) Удалить B
7) Создать → B (снова, т.к. слот освободился)
```

---

## Автоматическое сохранение результатов

Все операции (кроме «детерминант») автоматически сохраняют результат в первый свободный слот. То есть после `A + B` вы получите `C`, после `C * A` — `D`, и так далее.

Если хранилище заполнено:

```
Хранилище заполнено — результат не сохранён (только показан).
(без имени)
```

Результат всё равно будет выведен на экран, но в массив не попадёт.

---

## Формат вывода матрицы

Числа печатаются в формате `re±imi`:

```
1.0+2.0i 3.0+4.0i 
4.0+3.0i 2.0+1.0i 
```

Если мнимая часть отрицательна, плюс не ставится:

```
1.0-2.0i
```

- Очень маленькие числа обнуляются (защита от машинного шума).
- Строки разделены пробелами, столбцы — табуляцией/пробелами, строки — переносом.

---

## Что можно и что нельзя

| Действие | Можно | Нельзя |
|---|---|---|
| Имя матрицы | `A`, `a`, `AA`, `abc` | `AAA` (если индекс ≥ 1000) |
| Комплексное число | `3 4`, `3,4`, `-2.5 1e-3` | `3`, `3 4 5`, `a b`, `()` |
| Сложение | одинаковые размеры | разные размеры |
| Умножение | `cols(A) == rows(B)` | иначе — ошибка |
| Детерминант, обратная | только квадратная | не квадратная |
| Деление | `B` квадратная, невырожденная | иначе — ошибка |
| Отмена операции | ввод `0` в `askMatrix` | — |

## Известные особенности

1. **Погрешность `double`.** Ожидайте `1e-15` вместо чистого нуля. Это нормально.
2. **`Print()` мутирует матрицу**, но `Main.printMatrix()` делает защитную копию перед печатью, поэтому в массиве значения остаются нетронутыми.
3. **Детерминант может быть очень маленьким** (`3e-18`) — трактуйте как ноль.
4. **`doScalar` ждёт два отдельных ввода.** Если хочется один — см. замечание в разделе 5.
